## 호환과 조기 종료

콘텐츠hospital-core-stress-2는 E01~E06, 이전opening-core-stress-1은 E01~E04를 그대로 제공한다. 이전 규칙 JSON은opening-v1.json으로 보존했다. 이전 저장은 읽기/이어하기만으로 변경하지 않는다. 이전 E04 완료에서 **E05 병원으로 이동**을 선택하면 이름·수치·이력·난수를 유지한 연결 후보를 만든다. 저장 성공 후에만 새 형식으로 확정하고 실패는 동일 후보로 재시도한다.

부상3이면 결과 확인을 기다리지 않고 치명 부상 결말로 종료한다. 종료 결과와 실제 이름/성향/구조 판단/counts/대표 행동을 담은 Legacy를 한 저장 봉투에 기록한다. 미도달E07/E10 대표 행동은null이며 만들어 내지 않는다. 조기 종료 화면은 실제 변화와 계승 기록 요약을 표시한다. 새 회차 교체·동료 플레이는 제공하지 않는다.

UI 계약0.4.0, 저장schema5/hospital-solo를 사용한다. schema4/opening-solo도 명시적으로 지원한다. 자세한 공개 사용법은ui-integration.md, 저장은persistence.md를 따른다.
