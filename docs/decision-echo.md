# 이전 회차의 판단을 이어받는 동료

## 승인된 동작 — 2026-10-29

사용자가 D08 세부 제안에 “이 기준으로 구현”으로 답했다. 같은 상황이면 직전 인물이 실행했던 행동을 동료가 추천한다. 실제 실행은 플레이어가 결정하며 자동 선택·치료·숨은 선택 해제는 하지 않는다. 일반 본인4개, 극단 본인3개+동료1개 구성을 유지한다.

동일 상황은 사건·장소·구간·그룹·장면, 주인공 성향·체력·스트레스·부상·자원, 스토리 조건·방문 이력, 네 선택의 정의·목표·실행 가능 여부·실제 성공률이 같은 경우다. 이름·회차 번호·난수와 동료 존재 자체는 제외한다. 동료 때문에 행동 조건·효과가 달라지면 다른 상황이다. 물자 양보의 신뢰 상한으로 실제 신뢰 증가량이 달라지는 경우도 구분한다. 객체 키와 선택 배열의 나열 순서는 의미 차이로 보지 않는다.

이전 행동과 당시 치료 여부가 현재 실행 가능해야 한다. 선택이 없거나 잠겼거나 치료가 불가능하면 기존 추천으로 돌아간다. 상충하는 과거 판단으로 하나를 고를 수 없는 경우도 보류/기존 추천으로 돌아간다. 치료를 동반했던 행동은 의견에 치료 사실을 표시하지만 체크박스는 플레이어가 직접 선택한다.

대표 선택은 실제 기록된 E02/E07/E10 중 같은 사건의 목표만 참조한다. 일반 추천의 성향·생존·자원·명시 속도 비교가 끝난 최종 동률 안에서 해당 목표의 유일한 후보를 약하게 선호한다. 자원 교환관계, 알려진 속도와 미상 속도의 비교 불가, 같은 목표 안의 여러 후보 동률을 임의 점수로 해소하지 않는다. 과거 대표 선택이 현재 성향이나 더 안전한 행동을 일반적으로 덮어쓰지 않는다.

## 콘텐츠와 저장

신규 팩은 `catalog-decision-echo-1`이며 `decisionMemoryVersion=context-1`, `recommendationVersion=survival-1`과 다음 정책을 함께 사용한다.

```json
"decisionEcho": {
  "version": "echo-1",
  "compatibleRevisions": ["catalog-decision-memory-1", "catalog-decision-echo-1"]
}
```

호환 목록에는 현재 revision을 포함한다. 같은 pack/rules와 명시적으로 허용된 revision 사이에서만 과거 맥락을 비교한다. 이전 팩은 `src/test/opening-catalog-v14.json`에 고정했다. 구 저장은 기존 고정 팩과 규칙을 유지하며 없는 과거 상황을 생성하지 않는다. 이야깃말·행동 의미를 변경한 revision을 검토 없이 호환 목록에 추가하지 않는다. JSON 작성 모델은 과거 기록이나 임의 가중치를 만들지 않는다.

계약0.6.0·schema6/7/8 유지. 신규 동행은 `catalog-companion-echo-1`, 계승은 `catalog-succession-6`, 단독은 기존 runtime3이다. 콘텐츠는12장소/12사건/22그룹/88선택 항목/145문구를 유지한다. 의견 조회는 난수·기록·자원을 소비하지 않으며 저장 실패 후 같은 후보 재시도도 유지한다.

## 검증과 남은 범위

39파일483테스트로 동일/상이 맥락, 조건·효과 변경, 실제 첫 회차→계승, 치료, 극단3+1, 약한 동률 선호, 구 팩, 저장 실패 재시도를 검증했다. lint/build/content:check와 JSON Schema5개 재생성을 완료했다.

실제 브라우저의 무저장 체험으로 E01~E12를 완주한 뒤 새 회차를 시작했다. 이전 지름길 선택이 같은 초기 조건에서 추천됐고, 플레이어가 대신 안전한 길을 골라 정상 실행하는 것을 확인했다. [검증 화면](screenshots/decision-echo.png).

확장된 최신 프로토타입 목표 기준 추정 약85%. 다음은 D03 동료 자율 행동·명령·이탈/재회, 이후 D09 가변 분량과 두 회차 합계약15분 실측이다. D03의 구체적 고신뢰 경계·위험·재회 조건은 아직 확정하지 않았다.
