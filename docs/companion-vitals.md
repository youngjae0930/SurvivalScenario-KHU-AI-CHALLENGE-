# 플레이어·동료의 개별 생존 상태

2026-10-30 사용자 요청: 부상·체력 등을 개별 관리하고 동료의 부상 게이지를 반영하며, 동료만 사망했을 때 플레이어는 계속 진행한다.

## 점검 결과

이전 동료 문맥에는 신원·성향·신뢰만 있었고 스태미나·스트레스·부상은 없었다. 위임 또는 극단의 동료 행동도 주인공의 상태로 판정하고 신체 효과를 주인공에게 적용했다. 감염으로 동료만 사망했을 때의 진행은 이미 가능했지만, 위임 실패의 일반 부상이 주인공의 세 번째 부상을 만들면 게임이 끝날 수 있었다.

## 현재 동작

- 주인공과 동료의 스태미나·스트레스·부상을 독립 관리한다. 새 동료는 기존 초기 생존 기준과 같은 스태미나70·스트레스30·부상0으로 출발한다.
- 직접 행동의 신체 소모·회복·부상은 주인공에게, 명령 또는 극단의 동료 대안은 실제 수행 동료에게 적용한다. 판정도 수행자의 생존 상태·성향을 사용한다. 공용 물자·치료 도구·무기와 이야기 성과는 회차에 남긴다. 플레이어가 결정한 행동의 성향 변화는 기존대로 플레이어에게 적용한다.
- 부상은 각각0~3이다. 동료 부상3은 동료만 사망 처리하고 결과 확인 후 다음 장소로 진행한다. 주인공의 부상3이나 주인공 감염 사망만 사망으로 회차를 종료한다. 기존 탈출·구조 대기 결말은 유지한다.
- 사망한 동료는 추천·명령·이탈·재회·정비에 참여하지 않으며 치료로 부활하지 않는다. 감염 접촉의 실제 주인공 전염이 함께 발생했다면 주인공도 기존 규칙대로 사망한다.
- 정비 선택의 확인창에서 나/동료를 선택한다. 치료 도구1개는 선택한 사람의 부상만1 낮춘다. 대상 전환은 치료 체크를 해제하고 미리보기 토큰을 갱신한다.
- 상태 패널에 동료의 개별 스태미나·스트레스·부상 게이지와 동행/이탈/사망을 표시한다. 결과 변화와 미리보기에도 동료의 수치임을 명시한다. 명령 메타데이터의 예전 공유 피해 안내30개도 수정했다.
- 추천을 따른 손해의 신뢰 감소 방지는 유지한다. 기본 신뢰 평가는 실제 행동 수행자의 신체 손익과 공용 자원 결과를 사용하고, 추천 일치 시 음수 변화만0으로 보호한다.
- 이탈·재회 시 개별 상태를 보존한다. 계승은 이전 인물의 성향·판단을 전달하고 새 동료의 생존 수치는 초기화한다.
