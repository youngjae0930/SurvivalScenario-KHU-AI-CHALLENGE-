# 첫 극단 안내와 짧은 결말 회고

출처: [2026-10-29 사용자 결정](decisions-2026-10-29.md)의 D05/D06.

## 첫 극단 안내

회차 전체에서 최초 극단 도달 결과에1회 안내를 배치한다. 축별이나 극별로 반복하지 않는다. 22이하/78이상 경계는 기존 규칙을 유지한다. 이후 극단 도달·해제는 기존 상태창으로 확인한다. 장면 자체의 선택 제한 설명과 극단 상태 표시는 계속 제공한다.

순수 reflection 엔진은 실제 history의 성향 before/after로 설문 출발 성향을 복원하고 최초 극단 결과ID를 찾는다. 별도 표시 이력을 추측하거나 과거에 안내를 봤다고 생성하지 않는다. 저장된 동일 결과를 이어하면 같은 안내 문장을 표시하되 새로운 극단 발생으로 처리하지 않는다. 다음 결과나 다른 축에서는 반복하지 않는다. 팝업/추가 확인 클릭은 없다.

## 감정적 회고

기존 결말의 긴 시스템 설명 대신 짧은2문장 회고를 앞에 둔다. 출발→최종3축 변화, 실제 E02/E07/E10 대표 선택 최대3개, 동료에게 이어질 성향 특징을 덧붙인다.50은 중립으로 표현한다. 조기 종료는 실제 도달한 대표 선택만 표시하며2~3개를 맞추려고 없는 기록을 만들지 않는다. 회고는 플레이어 대상이며 동료가 과거 인물의 삶이나 죽음을 기억하는 대사가 아니다.

엔진은 기록 사실과 방향만 계산하고 한국어 회고는 content/texts/reflection.ts에서 관리한다. 앱이 기존 EndingViewModel.legacySummary와 ResultViewModel.consequences로 변환한다. UI는 계약만 소비하며 게임 상태를 계산하지 않는다. 공개 계약0.6.0 변경은 없다.

## 호환과 범위

신규 팩은 catalog-reflection-1, manifest의 선택 필드 presentationVersion=reflection-1로 표시 정책을 고정한다. 직전 팩은 opening-catalog-v11.json이다. 구 팩에 필드가 없으면 이전 표시를 그대로 사용한다. 콘텐츠·게임 수치·난수·이력·compact Legacy는 바꾸지 않았다. schema6/runtime2, schema7/recovery1, schema8/succession3은 유지한다.

D08 대표 행동의 약한 기계적 영향/동일 상황 재현과 D03 자율 행동·이별/재회는 아직 구현하지 않았다. 기존 traits/counts 판단을 새 요구가 완료된 것으로 설명하지 않는다.

## 검증

35파일420테스트 통과, lint/build/content:check 및 Schema 재생성 성공. 최초 도달/다른 축/재진입·해제/새 회차/저장 복원, 늦은 안정 극단 경로, 출발 성향 복원, 중립 회고, 없는 대표 선택 방지, 이전 저장 표시 유지, 상태/난수 불변을 검증했다.

실제 브라우저에서 모험30→22 첫 안내를 확인하고, 이후 안내 반복 없이 동행 회차를 E12까지 완주했다. 결말에 성향30→38/50→42/50→26, 실제 대표3선택과 계승 특징을 확인했다. docs/screenshots/brief-ending-reflection.png. 제품 저장은 변경하지 않은 무저장 체험이다. 개발 서버5173을 다시 실행했다.
