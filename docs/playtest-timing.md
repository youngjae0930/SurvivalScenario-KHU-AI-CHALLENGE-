# 두 회차 플레이 시간 점검

일반 플레이 주소에 `?playtest=1`을 붙이면 화면 아래에 시간 점검 도구가 나타난다. 개발 서버에서는 http://127.0.0.1:5173/?playtest=1 이다. 일반 게임의 저장·이어하기 규칙을 그대로 사용한다. 새 측정을 위해 기존 저장을 삭제하지 않는다.

1. 첫 설문에 답하기 전에 **시간 측정 시작**을 누른다.
2. 평소처럼 상황과 결과를 읽으며 첫 회차를 끝낸다.
3. 다음 회차를 시작해 계승 동료와 플레이한다. 둘째 결말까지 기록한다.
4. **시간 기록 내려받기**로 `sealed-city-playtest.json`을 저장한다.

자리를 비울 때는 일시정지한다. 기록은 현재 탭의 메모리에만 있으며 새로고침·탭 종료 시 사라진다. 이어하기나 사건 도중 측정 시작은 부분 기록으로 표시한다. 부분 기록은 완전한 두 회차 측정으로 보고하지 않는다.

설문, 사건별 상황 읽기·선택 고민(확인창 포함), 결과 읽기를 구분한다. 결말 도착 시 해당 회차 측정을 종료하므로 결말 회고 읽기와 다음 회차 출발 전 대기 시간은 합계에 포함되지 않는다. 다음 회차 설문은 둘째 기록에 포함한다. 다음 설문 취소는 미완료 둘째 기록을 버리고 이전 결말로 돌아간다. 최대 두 회차만 기록한다.

문서가 숨겨진 탭, 저장 대기, 수동 일시정지, 5초를 초과한 실행 간격은 제외 시간으로 집계한다. 마지막 항목은 브라우저 정지·절전 등 불확실한 공백을 보수적으로 제외하기 위한 것으로, 정밀한 활동 감지는 아니다. 표시된 탭을 둔 채 자리를 비우면 자동으로 알아내지 못한다.

공개 GameClient 스냅샷을 관찰하며 게임 명령·난수·저장 데이터를 수정하지 않는다. 계약0.7.0, 현재 콘텐츠·런타임·저장 버전은 유지한다. 기록 파일은 로컬 다운로드이며 외부 전송은 없다.

검증: 순수 누적기 4개 테스트에서 단계 분리, 일시정지/백그라운드/긴 공백 제외, 계승·취소·두 회차 상한, 이어하기 부분 기록을 확인했다. 무저장 개발 체험의 실제 브라우저에서 설문→E01 선택→결과, 일시정지/재개, 사건별 표시와 JSON 다운로드를 확인했다. 이는 사람이 두 회차를 약15분에 읽고 판단할 수 있는지 검증한 결과는 아니다.

증거: [측정 화면](screenshots/playtest-timing.png). 다음 작업은 사람의 플레이 기록을 바탕으로 막히는 선택, 체력·물자 부족, 긴 문구와 분량을 조정하는 것이다. 실제 기록 없이 목표 시간 달성을 선언하지 않는다.
