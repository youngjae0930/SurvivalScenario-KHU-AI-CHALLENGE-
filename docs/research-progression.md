# 연구동 E07 진행

2026-10-29 사용자가 D04 권고안을 명시적으로 승인했다. ‘내부 분석 극단의 physical=false/weaponBonus=false, 외곽 무기 분해 cognition−8/자료 포기 cognition+8’로 확정하고 실제 E07을 연결했다. 동료 추천·신뢰·파견 정책은 이 승인에 포함하지 않는다. 정신력 효과는 승인된 스트레스 반전 규칙을 따른다.

## 플레이 흐름

새 회차는 빌라→편의점→골목→관리실→병원 진입→병원 이탈→병원 부속 연구동까지 진행한다. 연구동은 중반부 필수 장소이며 병원 이탈 후에만 방문한다. 살아서 진행하면 회차당 한 번 등장한다. 기본 팩은 여전히 이 순서를 보존하며 다양한 대체 장소 콘텐츠를 추가한 것은 아니다.

병원에서 access를 확보했다면 내부 연결 통로로 자료실에 들어간다. 확보하지 못했다면 연구동 외곽의 중계기를 이용한다. 두 맥락 모두 동일 장소의 E07이며 내부 조사 행동을 외곽에서 실행할 수 없다. 내부에서 cognition≤22면 분석 극단 조사 네 방식으로 대체한다. 외곽에는 분석 극단이 적용되지 않는다.

| 맥락 | 네 선택 |
|---|---|
| 내부 일반 | 문서/단말기 조사 / 단서만 확인 / 치료 도구로 접점 세척 / 체력을 더 써 교차 검증 |
| 내부 분석 극단 | 즉시 해독 / 치료 도구로 정비 후 해독 / 물자로 배선 고정 / 체력을 더 써 끝까지 대조 |
| 외곽 | 무기 분해 가동 / 자료 포기 / 물자 두 개로 전원 연결 / 표지를 기록하고 천천히 이탈 |

내부 위험 판정은 분석 가중치1·physical=false·weaponBonus=false, access 보정+5다. 체력·부상·무기 보정은 없지만 비용 소모와 실패 부상은 있다. 스트레스60 초과−5/80 초과−10과 성향 보정도 적용한다. 치료 도구는 접점 세정/정비에 쓰며 내 상처를 치료하지 않는다.

## 행동 수치

비용은 체력/공용 물자/치료 도구 순서다. 일반 조사·단서·극단 즉시/준비·외곽 분해/포기는 기획 v1.2와 이번 D04 승인 값을 사용한다. 그 외 여섯 행동은 네 선택 고정 요청에 따라 이번에 추가한 초기 프로토타입 수치이며 원문 확정값이라고 표현하지 않는다. 성공률 base는 성향/상태/접근 보정 전 값이다.

## 통합과 저장

- 현재 팩은 id=opening, revision=catalog-research-1, 제목 ‘빌라에서 연구동까지’다. 장소7개·사건7개·선택 그룹11개·행동44개·스크립트76개다. 중반부 최소 방문3/최대8은 현재 구간 편집 설정이다.
- 엔진의 범용 경로·조건·수치 계산과 UI 계약0.5.0을 재사용한다. 앱의 시작 표시도 하드코딩된 병원 제목 대신 해당 팩 메타데이터를 사용한다.
- 신규 저장schema6는 이 팩을 고정한다. 기존schema4/5와 이전schema6 회차는 원래 여섯 사건을 유지한다. E07을 진행 회차에 자동 삽입하거나 기존 저장을 삭제하지 않는다.
- src/test/opening-catalog-v1.json은 두 선택 버전, opening-catalog-v2.json은 네 선택/여섯 사건 버전의 고정 대조 자료다. 새 콘텐츠 추가 때 수정하지 않는다.
- E07 결과 확인 뒤는 E08 경로 확인 대기이며 게임 결말이 아니다. 치명 부상은 실제 결과와 Legacy를 함께 저장하며 대표 E07 행동ID를 남긴다. 미도달E10은null이다. E08 이후/전체 탈출/동료/두 회차는 아직 연결하지 않았다.
