## 수치 조정

- E01 큰 도로: 스태미나 8 소모·스트레스 5 증가. 지름길: 스태미나 4 소모, 기존 위험 판정·무기 보상 유지.
- E03 관찰: 스태미나 8, 빠른 통과: 5. 안전과 시간/소모의 교환을 명확히 했다.
- 준비형 병원 진입·접점 정비·구조 등의 기본 성공률을 85로 조정해 도구 소모의 이점을 구분했다. 최종 확률은 기존 공식으로 산출한다.
- E06 철수로 상처가 저절로 치료되던 효과를 제거했다. 짐 포기/물자 소모/더 오래 걷기의 차이를 남겼다.
- E08 우회 비용 20→15. 극단 성공의 체력 환급을 줄여 이동만으로 체력이 늘어나는 결과를 없앴다.
- E09/E10 치료 도구를 쓰는 구조는 스태미나 7·기본 성공률 85. 직접 구조와 구분했다.
- 공통 회복량과 최종 탈출 조건은 유지했다.

## 검토 화면

개발 서버의 `/?content-preview=opening`은 사용자 저장을 건드리지 않는 새 체험이다.

## 검증

- 전체 자동 검사 564개 통과.
- TypeScript 검사·배포 빌드 통과.
- 실제 브라우저: 새 버전 단독 12사건 탈출과 별도 동행 체험의 JSON 동료 의견·결과 표시 확인. 이별·부재·재회는 새 버전 자동 실행·저장 복원 검사로 확인했고, 이전 수정본에서는 화면도 확인했다.
- 신뢰 계산·선택 우선순위·이탈/재회 조건은 바꾸지 않았다.
- 변경 전 콘텐츠는 opening-catalog-v20.json에 보관해 기존 저장 검증을 유지한다.
- 릴리스: `ver-0.1.2 스토리 점검 및 대사집 수정`.

## 플레이 후 대사 교정

지름길 성공을 느린 이동으로 표현하던 대사, 무부상 상태에서 상처를 단정하던 우회 추천, 음식 나눔에 붙던 구조 상황의 말끝을 고쳤다. 이별 가능 선택에서는 동료가 함께 같은 결정을 했다고 말하지 않고 뒤쪽을 돌아보는 반응으로 바꿨으며, 이별 대사도 뒤에 남은 동료의 말로 정리했다. 이전에 헤어졌다는 전제가 없어도 자연스럽도록 마지막 동행 대사도 교정했다. 추가 수치·시스템 변경은 없다.


## JSON 대사 연결로 변경

신규 팩은 catalog-dialogue-1이다. 사건·선택·효과 JSON은 1차 수정본을 유지하고, 추천·이별·재회 대사를 scripts/E01~E12.json으로 옮겼다. 성향별 성공/실패는 완성된 본문 변형으로 작성했다. 표시 전용 채널은 난수를 소비하지 않는다. 저장 스키마 번호는 유지하되 런타임 식별자를 새로 구분하며 직전 콘텐츠를 fixture v21에 동결했다. 기존 TS 대사는 그 직전 저장 복원에만 사용한다. 새 작성 기준은 dialogue-authoring.md를 따른다.

## 이번 구조 수정 파일

|파일|수정 이유|
|---|---|
|src/content/catalog/packs/opening/scripts/E01~E12.json|본문·성향별 결과·추천·이별·재회 대사 작성|
|src/content/catalog/packs/opening/manifest.json|새 대사 방식과 콘텐츠 버전 명시|
|src/domain/catalog.ts, src/content/catalog/schema.ts|추가 대사 슬롯과 버전의 형식 정의|
|src/engine/catalog/compile.ts|잘못된 참조·동료 조건·기본 의견 누락 검증|
|src/engine/catalog/dialogue.ts|조건에 맞는 대사 하나를 결정적으로 조회|
|src/engine/catalog/runtime.ts|실제 추천·이별·재회 상황과 표시 채널 연결|
|src/app/view-models/catalog.ts|새 JSON 문구 표시, 수치 계산 설명을 동료 발화에서 제외|
|src/storage/catalog-save.ts|새 런타임 식별자 지원과 구 저장 복원 유지|
|docs/content-authoring.md, content-model-prompt.md, dialogue-authoring.md|콘텐츠 작성 범위·추가 슬롯·조건·검증 기준 갱신|
|docs/content-schemas/manifest.schema.json, script.schema.json, pack.schema.json|실제 작성 형식과 공개 스키마 일치|
|src/engine/catalog/dialogue.test.ts, narrative.test.ts, src/test/opening-catalog-v21.json 등|표현 변화와 게임 결과 동일성·저장 호환 검증|

신규 대사의 표현 범위는 사건별로 관련 성향 축을 구분한 것이다. 모든 성향 조합에 고유 대사를 부여한 것은 아니다. 주인공의 생각·다른 생존자의 짧은 발화는 일부 본문에 추가했다. 이후 일반적인 대본 수정은 사건/문구 JSON에서 처리하면 된다.
