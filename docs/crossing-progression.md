# 붕괴 통로 E08 진행

2026-10-29. 사용자 ‘다음 스텝 먼저 진행…프로토타입 만들고 나서 확장’ 요청으로 E08을 연결했다. 목적지 선택 이동·랜덤 콘텐츠 대량 추가는 프로토타입 완주 뒤로 둔다. 새 외부 모델 호출이나 동료 정책을 승인한 것으로 해석하지 않는다.

## 플레이

연구동을 나와 격리 구역으로 향하는 붕괴 연결 통로를 건넌다. 장소는 중반부 필수 장소이며 연구동을 방문한 뒤에만 등장한다. 현재 경로는 회차 시작 때 정하며 이동 선택 분기를 새로 구현하지 않았다.

일반 상태에서는 발판 확인/직감 통과/물자로 발판 보강/긴 통로를 통한 확정 통과를 제공한다. cognition>=78이면 직관 극단이며 ‘cross’ 목표를 유지한 난간 도약/물자로 잔해 틈 통과/물자 두 개로 디딤판 연결/체력으로 좁은 틈 통과 중 고른다. cognition<=22는 E08 지정 극단이 아니다. 모든 그룹에 정확히 네 선택을 제공하며 자원이 없고 체력이0이어도 최소 한 행동은 실행할 수 있다. 이는 생존 보장이 아니다.

실패는 진행 정지가 아니라 부상·스트레스·비용을 안고 통과하는 결과다. 부상3이면 그 자리에서 정상 사망 결말과 실제 Legacy를 저장한다. 무사히 E08 결과를 확인하면 E09 격리 구역 대기 화면으로 이어진다. 대기 화면은 결말이 아니다.

## 수치와 출처

기획 v1.2 문단37/70/80/150/154 및 기술 설계2.4.3의 E08 규칙을 사용한다. 원문 mental 손실은 승인된 스트레스 반전으로 적용한다. 아래 네 원문 행동 외 brace/detour/support/squeeze는 네 선택 고정 요청에 맞춘 새 프로토타입 콘텐츠 수치다. 원문 확정값으로 표현하지 않는다.

비용은 스태미나/물자/치료 도구다. 위험 판정은 모두 physical=true, weaponBonus=false다. 성향 가중치는 cognition 단일 축1이다. 스트레스·체력·부상 보정을 적용하고 E07 내부 접근+5는 적용하지 않는다. E08은 자료·routeKnown·구조 판단을 바꾸지 않는다.
