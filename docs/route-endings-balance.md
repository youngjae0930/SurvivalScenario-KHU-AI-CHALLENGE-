# 경로별 탈출 결말과 성향 속도 조정 (2026-10-30)

후속 [두 회차 실화면 점검](playtest-2026-10-30.md)에서 브라우저 연결 복구·연구동/지하터널 완주와 동료 반응 보완을 수행했다. 아래는catalog-balance-1 당시 기록이며 현재 신규 팩은catalog-playtest-1이다. 사람의15분 실측은 여전히 남아 있다.

신규 기본 팩은 `stage19/catalog-balance-1`이다. 지하철의 성공 탈출은 **지하터널 탈출**, 학교 경유 외곽의 성공 탈출은 **도시 외곽 탈출**로 표시한다. 치료제 발견 결말은 유지하며 구조 대기·탈출 실패를 성공으로 바꾸지 않는다. 비용·탈출 조건·추첨은 추가하지 않았다.

사용자 승인으로 신규 팩의 행동 `traitDelta` 중 ±8을 ±4로 낮췄다(중복 정의·조건부 변형 포함181곳). 설문 초기 성향30/50/70, 극단 경계22/78, 감염 즉시 사망, 연구동 위험 회수 성공률−15%p는 유지한다. 같은 방향의 선택을 반복해야 극단에 도달한다. 비용·효과·성공 판정은 기존과 동일하다.

## 편집과 저장

- `src/content/catalog/packs/stage19/events/`: 장소별 성향 변화·행동·조건부 결말. 종착지는 `southern-tunnel.json`, `outskirts-checkpoint.json`이다.
- `src/content/catalog/packs/stage19/scripts/`: 장소별 상황·결과·회고.
- manifest의 `endingVersion: routes-1`에서 성공 탈출에 `tunnel-escape` / `outskirts-escape`를 사용할 수 있다. 일반 행동에 탈출 결말을 연결하면 등록을 거부한다.
- UI 계약0.11.0, fixtures의 `tunnelEnding` / `outskirtsEnding`. 결말은 앱이 제공하며 UI는 경로를 재계산하지 않는다.
- schema6/7/8 유지, 신규 런타임은 `catalog-runtime-9` / `catalog-companion-endings-1` / `catalog-succession-15`다.
- 직전 연구동 팩은 `src/test/research-catalog-v1.json`에 고정했다. 기존 저장은 이전 성향 변화·문구·결말을 그대로 사용한다. 새 출발 또는 명시적 다음 회차부터 새 팩을 적용한다. D08 동일 상황 비교는 새 revision 안에서 한다.

## 검증과 한계

59파일650테스트·lint·build·content:check 통과. 경로별 단독/동행 결말·미리보기·저장 복원·다음 회차 계승, 구조 대기 구분, 이전 팩 원문 보존, 저장 실패 후 동일 후보 재시도를 확인했다. 성향 변경 검사는 이전 팩과 행동 전체를 비교해 비용·판정·효과 보존도 확인한다. 빌드의 기존 콘텐츠 청크 크기 경고는 남는다.

`npm run content:balance`는 실제 등록 팩과 실행 엔진으로 **8시드×5경로 계획×3고정 정책×2연속 회차=240회**를 점검한다. 결과는 [조정 전](balance-before.json)과 [조정 후](balance-sample.json)에 있다. 첫 행동 이내 극단 도달은90→0회, 교착은 두 표본 모두0회다. 조정 후 관측된 가장 빠른 극단 도달은3번째 행동이다. 안전 우선 정책의 일반4경로는 각16회 모두19스테이지까지 진행했다.

이 수치는 고정 QA 정책의 재현 표본이며 플레이어의 생존 확률·재미·읽기 시간을 뜻하지 않는다. 실제 브라우저 확인은 제어 연결 오류(`browser.user is unavailable`)로 수행하지 못했고 사용자5173 저장은 수정하지 않았다. 두 회차15분 실측과 사람의 체감 난도 검토는 남아 있다.

요청한 경로 특징·감염·연구동 히든·새 탈출 결말의 최소 기능은 연결됐다. 다음은 실제 플레이 검토 후 난도·문구 조정이며, 장소별 추가 사건과 대량 스크립트는 확장 작업이다.
