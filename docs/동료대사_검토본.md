# 동료 대사 검토본

catalog-dialogue-1 · 실제 JSON 문구와 조건. 성향 변형은 사건별로 관련 축을 사용한다. 모든 축 조합에 고유 대사를 만든 것은 아니다. 기본/성향별 반응은 실제로 하나만 표시한다.

조건 표기는 원본 JSON을 짧게 표시했다. 50은 기본 동행 문구, 0~49/51~100은 축별 변형이다. 각 결과 항목은 게임에서 표시하는 전체 본문이다.
