# 동료 경험·서사 보강 로드맵

프로토타입 기능 구현 후의 개선 단계다. 사용자 플레이 피드백과 우선순위에 따른다. 보호 약속은 제외하며 새 시스템/수치를 임의 확정하지 않는다.

1. **동료 말투·선택 후 반응**: 계산 설명은 접는 상세 정보로 옮기고 본문은 상황의 걱정·이유·제안을 담는다. 자신의 추천 결과가 손해/실패라면 책임을 인정하는 반응을 연결한다. 편의점·붕괴 통로·병원 위임 장면부터 확인한다.
2. **추천과 신뢰 변화의 납득 가능성**: 추천의 예상 대가와 실제 결과를 함께 설명한다. 판단 보류에서도 인물의 고민을 보여 준다. 우선 기존 수치를 유지하고 표현 개선 후 남는 계산 문제를 검토한다.
3. **이별·재회**: 이별 당시 충돌·실제로 기록된 이후 결과·다시 동행하는 이유를 짧은 대사와 태도로 연결한다. 확인되지 않은 구조 성공/피해를 만들어 내지 않는다.
4. **서사와 규칙 정보 분리**: 이야기와 인물 반응을 우선하고 정확한 수치는 상세에 둔다. 성공 결과에 가정적 실패 안내가 남는 문제도 수정한다.
5. **선택 의미 정리**:4개 고정은 해제 완료. 중복 단거리 선택은 제거했다. 다른 장면에서도 필요한 만큼만 남기고 서로 다른 행동의 의미를 보강한다. 잠긴 경로와 무자원 대안은 유지한다.
6. **극단 도달 과정**: 제약 전에 고집이 굳어지는 독백/반응을 보강한다. 도달 속도의 수치 조정은 별도 검토한다.

공통적으로 사건별 JSON 확장과 실제 게임 기록에 기반하며 대사 때문에 추천·실제 결과가 모순되지 않게 검증한다. 이번에 완료한 범위는 선택 수 제한 해제와 E12 중복 제거다. 동료 대사·관계 표현 개선은 아직 구현 전이다.
