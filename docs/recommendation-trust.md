# 추천 행동의 신뢰 감소 방지

2026-10-30 사용자 요청: 동료의 추천을 따른 결과가 손해여도 신뢰를 깎지 않는다.

## 적용 기준

- 실행 전 실제 추천 ID와 선택 ID가 같으면 기존 결과 평가의 음수 변화만 0으로 만든다. 성공·실패 모두 적용하며 기존 상승과 0~100 범위는 유지한다. 추가 보너스는 없다.
- 일반·정비·과거 판단 추천, 극단의 동료 대안, 추천한 행동을 동료에게 맡기는 경우에 같은 기준을 쓴다.
- 추천 보류·비추천·동료 부재에는 적용하지 않는다. 비용·확률·피해·감염·명령 수락·이별 기준은 유지한다.
- 보호된 신뢰 유지 이유를 실행 기록에 남기고 성공·실패 미리보기에도 같은 결과를 표시한다.

## 추천과 기억 비교

추천을 정하려고 신뢰 미리보기를 조회하고 다시 추천을 조회하는 순환을 피하기 위해, 후보 비교는 보호 전 기본 평가를 쓴다. 실제 표시와 실행은 추천 결정 후 보호한다.

선택 당시 기록의 `trustOutcomes`는 실제 보호 후 예상 변화다. `baseTrustOutcomes`는 추천 결정 전 비교 근거로 별도 보존한다. 동일 상황의 기억 비교에는 이 기본 평가를 사용하고 실행 기록의 `trustChange`에는 실제 결과를 보존한다.

## 버전과 저장

신규 기본 팩은 `stage19/catalog-recommendation-trust-1`, 신뢰 정책은 `outcome-2`다. 이전 `catalog-story-1`은 `src/test/story-catalog-v1.json`에 고정한다. 기존 저장은 저장 당시 팩과 `outcome-1` 계산을 그대로 재생하며 새 출발/명시적 다음 회차부터 새 정책을 사용한다. 저장 슬롯 자동 삭제와 이전 기록의 소급 수정은 하지 않는다.

공개 UI 계약과 schema6·7·8은 유지한다. 새 런타임은 단독 `catalog-runtime-11`, 개발 동행 `catalog-companion-trust-2`, 실제 계승 `catalog-succession-17`이다. 의미 호환 revision은 새 팩 내부로 제한한다.
