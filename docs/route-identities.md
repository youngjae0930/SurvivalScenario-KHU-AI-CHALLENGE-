## 앞선 행동의 연속성

- 접수대 처치함 회수 → 수술방에서 그 도구를 누구에게 쓸지 떠올린다. 이미 도구가0이면 없다고 말한다.
- 홀의 식품 회수 → 식품관 배분을 자신의 앞선 회수와 연결한다. 물자가0이면 물을 구할 곳부터 생각한다.
- 개찰구 지도 확인 → 열차 연결부에서 작업 통로까지 가려면 이 위기를 지나야 함을 떠올린다.
- 운동장 출발 지원 → 행렬 붕괴에서 앞서 도운 사람을 찾지만 보이지 않는다고 말한다. 그 사람의 감염·생사·구조 결과는 만들어내지 않는다.

모든 회상은 실제 저장된 fact 조건으로만 표시한다. 단순히 해당 경로를 택했다고 획득하거나 도왔다고 말하지 않는다. 단순 정보 조사와 행렬 합류에 잘못 붙어 있던 “다른 이의 구조보다 자기 보존” 신뢰 이유도 실제 행동에 맞게 교정했다. 평가 가중치는 유지했다. 확정 정찰의 공동 실행 안내에서도 존재하지 않는 실패 부상 설명을 제거했다.
