# 네 선택 고정 변경

2026-10-29 사용자 요청 ‘선택지4개 고정으로 늘려줘’에 따라 신규 회차의 일반/극단 그룹 모두 정확히4개로 변경했다. 기존 E01~E06의 첫 두 행동은 원문 그대로 유지하고 그룹마다 두 행동을 추가했다. 일반6개·극단2개 그룹, 총32개 행동과54개 문구다. 신규 revision은 `catalog-opening-2-four-choices`다.

## 게임에서 달라지는 것

| 상황 | 추가된 두 선택 |
|---|---|
| E01 출발 | 지도를 대조해 경로 결정 / 호흡을 가다듬고 큰길 이동 |
| E02 편의점 | 내 치료 도구로 생존자 처치 / 안쪽 구급함에서 내 치료 도구 탐색 |
| E03 골목 | 체력 대신 긴장을 감수하며 기다리기 / 물자로 시선 돌리기 |
| E04 정비 | 체력 회복 없이 상처만 처치 / 체력을 써 주변을 정돈하고 스트레스 완화 |
| E05 일반 | 물자로 내부 통로 준비 / 체력을 더 써 천천히 우회 |

자원이 부족한 행동도 네 칸 안에 잠금 이유와 함께 표시한다. 네 행동이 항상 전부 실행 가능하다는 뜻은 아니다. 최소 하나의 무자원 기본 행동을 유지하며 E05 모험 극단은 내부 접근, E06 안정 극단은 철수 목표를 유지한다. 치료/탐색도 해당 장면을 소비하는 한 행동이다. 정비의 기존 선택적 치료는 유지하고 새 응급 처치와 중복 적용하지 않는다.

## 작성·저장 경계

새 event/pack JSON Schema는 선택 그룹 배열의 minItems/maxItems를 모두4로 지정한다. `compileCatalog`와 실제 파일 자동 등록은 기본적으로 이 스키마를 사용한다. 저장 디코더는 이전 고정 팩의 선택 수를 보존하기 위해 별도 `savedPackSchema`를 사용한다. 모든 형식·참조·경로·효과·복원 재현 검사는 유지한다. UI는 그룹에서 넘어온 행동을 표시하며 선택을 임의로 만들어 채우지 않는다.

schema4/5와 이전schema6 저장은 기존 두 선택으로 이어진다. 이 변경은 새 회차와 개발 전용 `/?content-preview=opening`에서 확인한다. 기존 저장 삭제·덮어쓰기나 새 회차 교체 UI는 추가하지 않았다. 엔진의 난수 알고리즘·기존 행동 계산·공개 계약0.5.0·저장schema6는 유지한다.

검증:23파일·259테스트, 콘텐츠 검사·린트·빌드 통과. 브라우저에서 네 선택 표시·새 선택 미리보기/실행·자원 부족 잠금도 확인했다. 원문 두 선택 회차의 복원과 새 선택 경로의 저장 재현은 자동 테스트로 검증했다.
