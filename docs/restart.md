# 처음부터 시작

저장된 여정이 있는 시작 화면, 플레이 중, 결말 및 다음 회차 준비 화면에서 **처음부터 시작**을 제공한다. 빈 첫 설문에는 표시하지 않는다.

버튼은 삭제 경고를 연다. 현재 진행과 해당 저장에 포함된 결말·계승 동료 기록이 모두 삭제되며 되돌릴 수 없음을 알린다. **취소하고 계속하기** 또는 Escape는 기존 화면과 저장을 유지한다. 기본 초점은 취소 버튼이다. **데이터 삭제 후 처음부터 시작**을 눌러야 초기화한다.

확정 시 게임 저장 슬롯만 제거한다. 성공 후 이름·설문부터 계승 없는 단독 첫 회차를 준비한다. 기존의 결말에서 **새 주인공과 다음 회차 시작**은 계승을 유지하는 별도 기능이다. 다른 앱의 브라우저 데이터나 저장 전체를 지우지 않는다.

앱의 단일 탭 잠금·원문 비교 후 삭제하며, 삭제 완료 전 화면을 전환하지 않는다. 실패 시 기존 화면·저장을 유지하고 같은 삭제 작업을 재시도한다. 다른 탭 또는 외부 변경 충돌은 삭제하지 않고 차단한다. 손상·미지원 저장은 기존 차단/보존 정책을 유지하며 이 기능으로 자동 제거하지 않는다.

공개 계약0.8.0은 경고 확인 후 `dispatch({ type: 'restart', confirmation: 'discard-saved-progress' })`를 받는다. 확인값 없는 명령은 거부한다. UI는 저장소에 직접 접근하지 않는다. 저장 어댑터의 선택적 `compareAndRemove(expected)`가 없으면 안전한 초기화를 지원하지 않는다고 안내하며 기존 진행을 보존한다. 성공한 초기화는 미리보기 토큰·계승 준비·이전 응답을 비운다. schema4/5도 명시적 초기화 후 새 출발에는 최신 catalog를 사용한다. 콘텐츠·저장 스키마·게임 규칙은 변경하지 않았다.

검증: 삭제 실패/재시도·외부 충돌/잠금·중복 처리·삭제 전 화면 유지·구 저장 초기화·동행 초기화 후 단독 출발·과거 토큰 거부, 게임 키만 삭제를 자동 검사했다. 별도15173 배포 빌드 브라우저에서 경고 취소→기존 결말 이어하기→삭제 확정→새로고침→새 단독 E01 출발→플레이 중 취소/삭제를 확인했다. 5173 사용자 저장은 수정하지 않았다. 브라우저 오류0건. [경고 화면](screenshots/restart-warning.png).

기능 구현 기준 프로토타입은 완료다. 실제 플레이 시간·밸런스·문구 완성도는 이후 점검/확장 단계로 구분한다.
