# 연락과 구조 E10 진행

2026-10-29. 다음 단계 요청에 따라 E10 단독 회차를 연결했다. 기획 v1.2 문단39/70/80/152/154와 기술 설계2.4.3을 기준으로 한다. 동료 추천·신뢰·보호 약속·파견 정책은 이번에 확정하지 않는다.

## 플레이와 앞선 선택의 영향

격리 구역 뒤 후반부 필수 장소인 외곽 통신소에 도착한다. 일반 상태에서는 신호 확인/구조/신호 보강/생존자 처치 구조의 네 선택이다. E02에서 도움으로 helpEstablished=true를 만들었다면 첫 행동만 ‘연락망으로 탈출 통로 확인’으로 바뀐다. 이 행동은 판정 없이 routeKnown=true를 만든다. 연락망이 없을 때 신호 확인은 routeKnown을 만들지 않는다. E09에서 사람을 돕는 것만으로 E02 연락망을 새로 만들지 않는다.

affect>=78의 감정 극단에서는 연락망 유무보다 구조 목표가 우선한다. 즉시 진입/물자 받침/치료 도구 보호/체력으로 우회 진입 네 방식이다. 무자원 기본 행동은 체력0에도 실행 가능하지만 생존은 보장하지 않는다. 물자·도구·고강도 체력이 부족한 행동도 잠금 이유와 함께 표시한다. 이성 극단은 E10을 제한하지 않는다.

확인 행동은 self, 구조 행동은 rescue로 judgmentCounts에 한 번 기록한다. 성패에 관계없이 의도를 기록하고 E02의 rescueDecision/helpEstablished를 보존한다. 신호 확인과 구조는 기존 routeKnown=true를 지우지 않는다. E10은 기존 대표 슬롯에 실제 action ID를 기록한다. 구조 대상은 현재 회차의 동료로 추가하지 않는다. NPC에게 쓰는 치료 도구가 내 부상을 동시에 치료하지 않는다.

정상 결과 확인 뒤는 E11 대기다. E12의 우회 조건에 사용할 정보는 얻을 수 있지만, 실제 E12 탈출 화면은 이번 범위가 아니다. 부상3이면 실제 사망 결말과 이번 판단을 포함한 Legacy를 함께 저장한다.

## 수치와 출처

비용은 체력/물자/치료 도구다. signal/network/rescue/rush/prepare는 원문과 공통 템플릿을 적용했다. beacon/aid/wrap/haul은 네 선택 고정 요청에 따른 추가 프로토타입 수치다. 추가 수치를 원문 확정값으로 표현하지 않는다.

haul은 체력20 이상을 요구한다. 모든 위험 행동은 physical=true, 감정 가중치1, weaponBonus=false다. 선택 전 체력·부상·스트레스·성향으로 판정하고 E07 접근 보정은 적용하지 않는다. 준비형은 성공 보상을 받기 전에 물자1을 보유해야 하며 성공 시 물자 순변화는0이다. 실패해도 비용은 돌려주지 않는다.

즉시형 성공은 템플릿 mental−5와 사건 mental+10을 합산한 mental+5, 즉 스트레스−5다. 준비형은 mental+10을 스트레스−10으로 반전한다. 일반 구조의 성공에는 스트레스 보상을 추가하지 않는다. 자원·성향·스트레스 상한과 하한은 공통 엔진을 따른다. 원문의 sharedGoalAchieved는 동료 기여/신뢰 시스템 연결 때 다룬다. 현재 단독 회차에서 가짜 동료 태그나 신뢰 기록을 생성하지 않는다.
